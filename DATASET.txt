# Dataset Information

> **EfficientCaps — Degraded Traffic Sign Recognition**  
> **Author:** Mansoureh Fahimi

## German Traffic Sign Recognition Benchmark (GTSRB)

The **German Traffic Sign Recognition Benchmark (GTSRB)** is a large-scale,
real-world traffic sign classification dataset collected from German roads.
It is a standard benchmark for traffic sign recognition research.

### Dataset Overview

| Property | Details |
|---|---|
| **Dataset** | German Traffic Sign Recognition Benchmark (GTSRB) |
| **Classes** | 43 traffic sign categories |
| **Total Images** | 51,839 |
| **Training Set** | 39,209 images |
| **Training Used** | 35,289 images after validation split |
| **Validation Set** | 3,920 images (10% held out from training) |
| **Test Set** | 12,630 images |
| **Input Size** | Variable originally → resized to **48 × 48** |
| **Color Format** | RGB (3 channels) |

---

## Dataset Access

The dataset itself is **not distributed with this repository** due to its
size. It is publicly available from the original source and through
Hugging Face.

**Hugging Face dataset used in this project:**  
https://huggingface.co/datasets/tanganke/gtsrb

**Official GTSRB website:**  
https://benchmark.ini.rub.de/gtsrb_news.html
